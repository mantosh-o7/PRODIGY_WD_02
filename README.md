⏱️ ChronoPulse — Precision Stopwatch

A modern, responsive, and feature-rich stopwatch web application built with HTML, CSS, and JavaScript.

ChronoPulse provides accurate time tracking with lap recording, performance statistics, keyboard shortcuts, sound feedback, and CSV export — all wrapped in a sleek, interactive interface.

📌 About The Project

ChronoPulse was developed as part of the Prodigy InfoTech Web Development Internship — Task 2.

The goal of this project is to create an interactive stopwatch application that allows users to start, pause, reset, and record lap times while providing useful timing analytics.

The application uses a circular animated progress indicator and a digital timer interface to provide a modern user experience.

🎯 How To Use
Open the application in your browser.
Click Start or press Space to begin timing.
Click Lap or press L to record a lap.
Continue recording laps as required.
View your fastest, average, and slowest lap times.
Use Copy to copy lap records to your clipboard.
Use Export CSV to download lap data.
Click Reset or press R to reset the stopwatch.
📊 Lap Analytics

ChronoPulse automatically analyzes recorded laps and displays:

Fastest Lap — Shortest recorded lap duration
Average Lap — Average duration of all recorded laps
Slowest Lap — Longest recorded lap duration

Each lap also records its individual split time and total elapsed time.
